> 项目：STM32F103ZET6 红牛开发板，蜂鸣器 `BEEP/BOOT1` = PB2（GPIOB / GPIO_PIN_2，LQFP144 pin 48）
> 生成日期：2026-11-12 ｜ 平台：Windows + PowerShell ｜ 开发前端：CodeBuddy IDE
> 只读输入：`@docs/hardware_pins.md`（锁定版：PB2 无 TIM 通道、`{PWM_FALLBACK_PIN}` = CN1 PWM0=PB0/TIM3_CH3、PWM1=PB1/TIM3_CH4；JP5 BEEP 使能；R39 1K → Q1 NPN → 蜂鸣器；5V 供电）、`@docs/stage2_manual_notes.md` M6（手册 CN1 针序与锁定版不同、`JP12` 默认不安装）、`@docs/env_check.md` 第 5 节硬件禁忌

## 1. 路径 A（当前实施）：无需任何飞线与跳线改动

| 项 | 说明 |
| --- | --- |
| 实现方式 | TIM2 更新中断（10 kHz）按段频率/占空比翻转 PB2（软件 PWM），`Core/Src/buzzer.c` |

| 硬件前提 | 已具备（阶段 1 实测：有源、高电平有效；PB2 推挽输出即可驱动 Q1） |
| 上限 | 有源蜂鸣器只有通断节奏/占空比语义，无音调变化（物理限制） |

## 2. 路径 B（备查，本阶段不实施）：飞线硬件 PWM

**语义**：把蜂鸣器驱动输入从 PB2 改接到 `TIM3_CH3`(PB0) 硬件 PWM 输出，用 `HAL_TIM_PWM_Start` 产生精确频率/占空比方波。对**有源**蜂鸣器仍只有通断质感；对无源蜂鸣器频率即音调（与路径 C 配合）。

**改线前提（全部满足才可实施，且需当轮用户显式授权）**：

1. **CN1 针序人工复核**：锁定版实测 CN1 = pin4 `PB0/PWM0`、pin5 `PB1/PWM1`，但 `@docs/stage2_manual_notes.md` M6 记录手册针序为 `4 GND / 5 PWM0 / 6 PWM1 / 7 GND`，两者不同 → 飞线前必须断电用万用表通断档实测「CN1 待用针 ↔ PB0/PB1 引脚（LQFP144 pin 46/47）」连通性，以实测为准。
2. **断电操作**：拔除电源（JP4/J3），严禁带电焊接/插拔（`@docs/env_check.md` 硬件禁忌 #10）。
3. **断开原 PB2 侧**：飞线后 PB2 侧驱动必须断开（通常从 JP5 的 PB2 侧断开或摘除 JP5 跳线帽），否则软件 PWM 与硬件 PWM 双驱动冲突。

**改线步骤（示意，实施前逐项复核）**：

| # | 步骤 | 说明 |
| --- | --- | --- |
| 1 | 断电，确认 0 V | 万用表量 JP5 两端与 5V 轨 |
| 2 | 复核 CN1 针序 | 通断档确认 PB0 ↔ 待用 CN1 针（对照锁定版 pin4 与手册 pin5 的差异，M6） |
| 3 | 断开 PB2 侧 | 断开 JP5 的 PB2 侧连接（或摘帽），确认 PB2 不再接驱动 |
| 4 | 飞线 | CN1 PWM0 针（PB0）→ JP5 的驱动输入侧（原接 BEEP 网络/R39 1K 前端）；GND 已由板内共地，无需另接 |
| 5 | 上电前检查 | 万用表确认无短路；JP5/JP9 状态记录 |
| 6 | 固件配合 | 新增 TIM3 PWM 初始化（`HAL_TIM_PWM_Start`），PB0 配 `GPIO_MODE_AF_PP`；**须按 `@docs/stage2_hal_source.md` 规则同步官方源与模块宏**（TIM 模块已启用，无需新增） |
| 7 | 重新验证 | 频率/占空比用示波器或 GDB 读 TIM3 PSC/ARR/CCR 核对（误差 <2%，附录 B #23） |

**共地要求**：PB0 与蜂鸣器驱动同板共地，无需额外地线；若用外部电源验证蜂鸣器支路，必须与板 GND 共地。

## 3. 路径 C（备查，本阶段不实施）：更换无源蜂鸣器 + 路径 B

在路径 B 基础上增加硬件改动：把 `DZ1` 位置的有源蜂鸣器更换为无源蜂鸣器（需焊接）。

**与路径 B 的验收差异**：

| 项 | 有源（路径 A/B） | 无源（路径 C） |
| --- | --- | --- |
| 频率语义 | 断续节奏（非音调） | **频率 = 音调**，可变频变调 |
| 驱动要求 | 电平通断即可 | 必须方波驱动（路径 B 硬件 PWM 优先；软件 PWM 也可但音质差） |
| 频率范围 | 1–50 Hz 节拍 | 需匹配谐振频率（常见 2–4 kHz），须实测蜂鸣器规格 |
| 验收 | 听「响/停节奏」 | 听「音调/旋律」，频率误差以示波器或听感核 |
| 占空比 | 音量/断续质感 | 音色/响度，一般 50% |

**风险**：焊接换件属不可逆硬件改动；谐振频率不匹配时可能无声或音量很小；更换后 `{BUZZER_TYPE}` 实测结论（锁定版）将失效，须重新实测并经用户确认后才能改写（本阶段不改写锁定版）。

---

## 4. 通用禁忌（改线实施时）

- 改线/焊接/插拔前**必须断电**；禁止带电操作（`@docs/env_check.md` #1/#10）。
- 5V 仅供蜂鸣器支路，不得接到 3.3V 引脚（#2）。
- 不复用 PA13/PA14、不做 SWJ remap；飞线走线远离 J5 调试排线。
- 任何改线后第一次上电先空载检查电流/温升，再烧录验证。
- **本阶段一律不实施以上 2/3 节内容**；当前固件与文档均基于路径 A。
